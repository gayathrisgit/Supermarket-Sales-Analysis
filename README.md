# Supermarket Sales Analysis Dashboard

## Project Overview
This project analyzes supermarket sales data using Microsoft Power BI. The dashboard helps understand sales performance, profit, product categories, payment methods, and customer distribution.

## Key Performance Indicators (KPIs)
- Total Sales: 524.89K
- Total Profit: 100.92K
- Total Orders: 200
- Average Sales: 2.62K
- Total Quantity: 1K

## Dashboard Features
- Sales by Category
- Sales vs Profit Analysis
- Monthly Sales Trend
- Payment Mode Distribution
- Profit Analysis by Category
- Sales by Product
- Profit by City
- Sales by Gender

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis

## Skills Demonstrated
- KPI Cards
- Bar Charts and Pie Charts
- Trend Analysis
- Data Filtering
- Dashboard Design

## Conclusion
This dashboard provides an overview of supermarket sales and profit performance across different product categories, cities, payment methods, and customer groups.
